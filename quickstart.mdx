---
title: "Quickstart"
description: "Run your first blackbox probe in under five minutes."
---

<Steps>
  <Step title="Download or pull the exporter">
    **Binary:** Download the latest release for your platform from the [GitHub releases page](https://github.com/prometheus/blackbox_exporter/releases).

    **Docker:** Pull the image directly — no download needed.

    ```bash
    docker pull quay.io/prometheus/blackbox-exporter:latest
    ```
  </Step>

  <Step title="Create a minimal blackbox.yml">
    Save the following as `blackbox.yml` in your working directory. This defines the `http_2xx` module used in the next steps.

    ```yaml blackbox.yml
    modules:
      http_2xx:
        prober: http
        http:
          preferred_ip_protocol: "ip4"
    ```
  </Step>

  <Step title="Start the exporter">
    <Tabs>
      <Tab title="Binary">
        ```bash
        ./blackbox_exporter --config.file=blackbox.yml
        ```
      </Tab>
      <Tab title="Docker">
        ```bash
        docker run --rm \
          -p 9115:9115 \
          --name blackbox_exporter \
          -v $(pwd):/config \
          quay.io/prometheus/blackbox-exporter:latest --config.file=/config/blackbox.yml
        ```
      </Tab>
    </Tabs>

    The exporter starts and listens on port `9115` by default. You should see output similar to:

    ```
    time=... level=INFO msg="Starting blackbox_exporter" ...
    time=... level=INFO msg="Loaded config file"
    time=... level=INFO msg="Listening on" address=[::]:9115
    ```
  </Step>

  <Step title="Run your first probe">
    In a second terminal, send a probe request targeting `prometheus.io` using the `http_2xx` module:

    ```bash
    curl "http://localhost:9115/probe?target=prometheus.io&module=http_2xx"
    ```

    The response is a Prometheus-formatted metrics page describing the outcome of the probe:

    ```text
    # HELP probe_success Displays whether or not the probe was a success
    # TYPE probe_success gauge
    probe_success 1
    # HELP probe_duration_seconds Returns how long the probe took to complete in seconds
    # TYPE probe_duration_seconds gauge
    probe_duration_seconds 0.196876958
    # HELP probe_http_status_code Response HTTP status code
    # TYPE probe_http_status_code gauge
    probe_http_status_code 200
    # HELP probe_http_ssl Indicates if SSL was used for the final redirect
    # TYPE probe_http_ssl gauge
    probe_http_ssl 1
    ```
  </Step>

  <Step title="Check probe_success">
    Look for `probe_success` in the output:

    - `probe_success 1` — the probe succeeded
    - `probe_success 0` — the probe failed

    This is the primary metric to alert on. All other metrics provide detail about what happened during the probe.
  </Step>
</Steps>

## Debug mode

Add `debug=true` to the probe URL to get full probe logs inline alongside the metrics output. This is useful for troubleshooting failed probes.

```bash
curl "http://localhost:9115/probe?target=prometheus.io&module=http_2xx&debug=true"
```

The response prepends a `Logs for the probe:` section before the metrics, showing each step the prober took, including DNS resolution, redirects, TLS handshakes, and HTTP responses.

<Note>
  You can also use the built-in web UI at `http://localhost:9115` to browse recent probes and access debug logs interactively.
</Note>

## Prometheus scrape config

The Blackbox Exporter implements the [multi-target exporter pattern](https://prometheus.io/docs/guides/multi-target-exporter/). Prometheus passes the target as a query parameter via relabeling — the exporter itself is the actual scrape target.

```yaml prometheus.yml
scrape_configs:
  - job_name: 'blackbox'
    metrics_path: /probe
    params:
      module: [http_2xx]  # Look for a HTTP 200 response.
    static_configs:
      - targets:
        - http://prometheus.io    # Target to probe with http.
        - https://prometheus.io   # Target to probe with https.
        - http://example.com:8080 # Target to probe with http on port 8080.
    relabel_configs:
      - source_labels: [__address__]
        target_label: __param_target
      - source_labels: [__param_target]
        target_label: instance
      - target_label: __address__
        replacement: 127.0.0.1:9115  # The blackbox exporter's real hostname:port.
  - job_name: 'blackbox_exporter'  # Collect blackbox exporter's operational metrics.
    static_configs:
      - targets: ['127.0.0.1:9115']
```

The relabeling rules rewrite `__address__` (the target URL) into the `__param_target` parameter before routing the scrape to the exporter at `127.0.0.1:9115`.
