---
title: "Installation"
description: "Install Blackbox Exporter via binary, Docker, or build from source."
---

The Blackbox Exporter listens on port `9115` by default. The `/probe` endpoint accepts probe requests, and `/metrics` exposes the exporter's own operational metrics.

<Tabs>
  <Tab title="Binary">
    Download the pre-built binary for your platform from the [GitHub releases page](https://github.com/prometheus/blackbox_exporter/releases).

    After downloading and extracting the archive, run the exporter with a config file:

    ```bash
    ./blackbox_exporter --config.file=blackbox.yml
    ```

    To verify the exporter is running, open `http://localhost:9115` in your browser or run:

    ```bash
    curl http://localhost:9115/-/healthy
    ```
  </Tab>
  <Tab title="Docker">
    Run the exporter using the official image from Quay, mounting your local `blackbox.yml` into the container:

    ```bash
    docker run --rm \
      -p 9115/tcp \
      --name blackbox_exporter \
      -v $(pwd):/config \
      quay.io/prometheus/blackbox-exporter:latest --config.file=/config/blackbox.yml
    ```

    The container exposes port `9115`. The `-v $(pwd):/config` flag mounts your current directory into the container so the exporter can read your config file.

    <Note>
      If you need IPv6 support, you may need to [enable IPv6 in your Docker configuration](https://docs.docker.com/engine/daemon/ipv6/).
    </Note>
  </Tab>
  <Tab title="Build from source">
    Building from source requires Go. Clone the repository and run `make`:

    ```bash
    git clone https://github.com/prometheus/blackbox_exporter.git
    cd blackbox_exporter
    make
    ```

    The compiled binary is placed in the project directory. Run it with:

    ```bash
    ./blackbox_exporter --config.file=blackbox.yml
    ```

    To build a Docker image from your local build:

    ```bash
    docker build -t blackbox_exporter .
    ```
  </Tab>
</Tabs>

## CLI flags

View all available flags by running:

```bash
./blackbox_exporter -h
```

The key flags are:

| Flag | Default | Description |
|------|---------|-------------|
| `--config.file` | `blackbox.yml` | Path to the configuration file. |
| `--web.listen-address` | `:9115` | Address to listen on for the web interface and telemetry. |
| `--timeout-offset` | `0.5` | Seconds to subtract from the probe timeout to allow for network delays. |
| `--log.level` | `info` | Log level for application logs. One of: `debug`, `info`, `warn`, `error`. |
| `--log.prober` | `info` | Log level for probe request logs. One of: `debug`, `info`, `warn`, `error`. |
| `--web.config.file` | | Path to a web configuration file for TLS and basic authentication. |
| `--config.check` | `false` | Validate the config file and exit without starting the server. |
| `--config.enable-auto-reload` | `false` | Automatically reload the config file when changes are detected. |
| `--config.auto-reload-interval` | `30` | Interval in seconds between config file change checks. |
| `--web.route-prefix` | | Prefix for internal web endpoint routes. Defaults to the path portion of `--web.external-url`. |

## TLS and basic authentication

The exporter supports TLS and basic authentication via the `--web.config.file` flag. This applies to all HTTP endpoints: `/probe`, `/metrics`, and the web UI.

```bash
./blackbox_exporter --config.file=blackbox.yml --web.config.file=web.yml
```

The web configuration file format is described in the [exporter-toolkit documentation](https://github.com/prometheus/exporter-toolkit/blob/master/docs/web-configuration.md).
